# Mein erstes Skript in Unity & C#

Dies ist ein kleines Einsteiger-Skript für die Unity-Engine, das ich für meine Bewerbung als Spieleentwickler erstellt habe.

##  Was das Skript macht
Es definiert grundlegende Variablen (`int` für ganze Zahlen und `float` für Kommazahlen) und gibt diese beim Start des Spiels in der Unity-Konsole aus.

##  Verwendeter Code
* **Engine:** Unity
* **Sprache:** C#
* **Konzept:** Variablen-Deklaration und Nutzung der `Start()`-Methode sowie `Debug.Log`.
